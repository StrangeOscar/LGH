Lorugum Boss Reports app

Host it like the guest house app: create a NEW GitHub repository (for example lorugum-boss), upload these six files, then Settings > Pages > Deploy from branch main / root.
Open the address on the boss's phone and Add to Home Screen.
When a report message arrives on WhatsApp or email, copy the whole message and paste it into the app, then tap Add report.
Reports are stored on this phone only.
